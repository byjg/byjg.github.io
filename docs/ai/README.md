# AI

Tools that connect AI assistants to the ByJG projects and to your terminal.

| Project | What it does |
|---|---|
| [ByJG Docs MCP Server](mcpserver-byjg-docs/README.md) | Gives any MCP client semantic search over the documentation of every ByJG project, with the source page cited |
| [Parolsh](parolsh/README.md) | A shell where natural language is the default command language, working with any ACP agent |
| [Agent Skills](agent-skills/README.md) | Skills that teach a coding agent (Claude Code, Codex, Cursor, ...) how to work with the ByJG components, installed from the [byjg/skills](https://github.com/byjg/skills) catalog |

The first makes the documentation on this site context for an assistant. The
second is where you talk to that assistant while you work. How both relate to
the other projects is in [The ByJG Ecosystem](../opensource/ecosystem.md).
